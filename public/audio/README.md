# Echoes 03:14 - Thư mục Nhạc nền & Âm thanh tùy biến (Custom Audio)

Hệ thống **Hybrid Audio Engine** của game tự động hỗ trợ phát các file âm thanh chất lượng cao đặt tại thư mục này. Nếu không tìm thấy file, game sẽ tự động sử dụng bộ sinh âm thanh nền và nhạc cụ thời gian thực (Procedural Web Audio Synthesis).

## Các định dạng và tên file được hỗ trợ:
- `bgm_menu.mp3` : Nhạc nền màn hình Menu chính (Melancholic Lo-Fi Piano).
- `bgm_intro.mp3`: Nhạc nền đoạn mở đầu tiềm thức.
- `bgm_room314.mp3`: Nhạc nền Màn 1 (Phòng trọ 314 - Dark Ambient).
- `bgm_sunset.mp3`: Nhạc nền Màn 2 (Bến Bình An - Nostalgic Piano / Ghibli Waltz).
- `bgm_pixelbleed.mp3`: Nhạc nền Màn 3 (Sự xâm thấu của thực tại - Glitch / Distorted).

> **Lưu ý:** Bạn có thể sử dụng các file định dạng `.mp3`, `.ogg`, `.wav`. Hệ thống sẽ tự động áp dụng bộ lọc Tỉnh táo (Sanity Filter) lên bất kỳ bài nhạc nào được phát!
